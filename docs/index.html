为什么不一样

大多数轻量阅读器把标注画在自己的界面上，换台电脑或发给别人就消失了。PDF Studio 导出的是标准 PDF 注释对象。

A

真实注释对象

高亮、下划线、删除线、方框、箭头、墨迹、便签分别写成 /Highlight、/Underline、/StrikeOut、/Square、/Line、/Ink、/Text。Adobe Reader、Edge、微信里都能看到。

B

原件永不改动

标注只存在本机数据库里。只有你主动导出时，才另存一份带注释的新 PDF，原始文件一个字节都不动。

C

笔记自成体系

可嵌套文件夹、全文搜索、Markdown 编辑预览，一键把选中文字连页码出处插进当前笔记，不依附于某一份 PDF。

D

数据握在你手里

关窗强制落盘、滚动备份、损坏自动留副本并告警、完整备份可合并或覆盖恢复。没有遥测，没有账号。

常见疑问

关于隐私、许可与文件安全。

我的 PDF 和笔记会被上传吗？

不会。软件没有账号、没有服务器、没有遥测，所有阅读、标注、搜索、导出都在本机完成。唯一可能的出站请求是你手动点击「帮助 → 检查更新」时向 GitHub 发的一次匿名 GET，不含任何标识。详见 PRIVACY.md。

公司里用算商业用途吗？

通常算。企业、工作室等经营性组织在日常业务中使用，或把软件作为付费产品、服务的一部分提供，都需要单独书面商业授权。有疑问请按「需要授权」处理并联系版权所有者。

导出的 PDF 在别的阅读器里能看到标注吗？

能。导出的是标准 PDF 注释对象，Adobe Reader、Edge、Chrome 与微信内置查看器都能显示。注意：对带数字签名的 PDF 另存副本可能使原签名失效，请务必保留原件。

扫描版 PDF 能选中文字高亮吗？

不能。没有文字层的扫描件只能使用框选区域、箭头、笔刷与便签。需要选字高亮请先做 OCR。

换电脑或重装后数据还在吗？

卸载不会自动删除数据。迁移前请用「导出中心 → 完整备份 → JSON」，在新机器用「文件 → 导入备份 / 恢复数据」，可选合并或覆盖。数据默认在 %APPDATA%\pdf-studio\。

为什么首次运行被 SmartScreen 拦？

当前 exe 未做代码签名。可点「更多信息 → 仍要运行」；正式商业分发版本会配置代码签名证书消除该提示。
